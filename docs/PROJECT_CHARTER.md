# Project Charter

## الهدف العام للمشروع
المشروع عبارة عن منصة SaaS قابلة للتوسع توفر موظفي AI لخدمة العملاء والمبيعات للشركات والمحلات.

الموظف يستطيع مستقبلاً العمل عبر عدة قنوات، أهمها:
- WhatsApp
- Web Chat
مع إمكانية إضافة قنوات أخرى مستقبلاً.

كل شركة/متجر يحصل على وكيل AI خاص به، ببياناته وإعداداته وعملائه وطلباته، مع عزل كامل للبيانات بين العملاء.

النسخة الأولى (MVP) تعتمد قدر الإمكان على الموارد المجانية أو منخفضة التكلفة، لكن يجب عدم بناء النسخة المجانية بطريقة تجعل الانتقال مستقبلاً إلى بنية تجارية أو قواعد بيانات ضخمة أمراً صعباً.

## الأدوار الرسمية
- **صاحب المشروع:** المستخدم (صاحب القرار التجاري والنهائي).
- **مهندس المشروع والمعمارية:** ChatGPT (مسؤول عن وضع المعمارية، خارطة الطريق، تحديد المبادئ، منع الانحراف المعماري).
- **منفذ المشروع:** Google AI Studio (تنفيذ التعليمات، كتابة الكود، الاختبار، إصلاح الأخطاء، الإبلاغ عن التعارضات، دون اتخاذ قرارات معمارية كبيرة منفردة).
